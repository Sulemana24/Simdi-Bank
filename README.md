🏦 Banking Website

This is a Banking Website developed as part of a school project using HTML, CSS, and JavaScript. The project demonstrates how a simple banking system can be represented on the web with a clean user interface and interactive features.

📖 Project Description

The Banking Website simulates basic banking operations. It allows a user to log in, check their account balance, perform deposits and withdrawals, and view a transaction history. The purpose of this project is to practice frontend web development skills and apply knowledge of JavaScript, HTML, and CSS.

🚀 Features

User login (simulation)

Display of account balance

Deposit and withdrawal functions

Transaction history tracking

Responsive design for desktop and mobile

🛠️ Tools and Technologies

HTML5 – page structure

CSS3 – styling and layout

JavaScript (ES6) – interactivity and logic

🎯 How to Use

Open the index.html file in any modern browser.

Log in using the demo account (if provided).

Perform banking operations such as checking balance, depositing, and withdrawing money.

View transaction history on the page.
